# Электронная нагрузка 60 Вт: схема и сборка

Аппаратная часть для прошивки `Firmware/load` (проект IAR `Firmware/EWARM/electronic_load.ewp`, `make load`). Все номиналы ниже совпадают со значениями по умолчанию в [`Firmware/load/load_config.h`](../Firmware/load/load_config.h). Если ставите другие детали, поменяйте их и там.

## Основные параметры

| Параметр | Значение |
|---|---|
| Режим | постоянный ток (CC) с ограничением мощности |
| Мощность | до 60 Вт (`LOAD_MAX_POWER_MW`), при высоком напряжении ток автоматически снижается до P/U |
| Ток | 0…10 А (`LOAD_MAX_CURRENT_MA`), шаг установки около 2.6 мА (ШИМ 12 бит) |
| Напряжение | 0.5…30 В (`LOAD_MAX_VOLTAGE_MV`), выше 30 В нагрузка не включается |
| Измерение U | ADS1115, 16 бит, дифференциально по Кельвину, около 1.4 мВ на младший разряд |
| Измерение I | ACS712-20A через ADS1115 (или шунт, см. ниже) |
| Температура | датчик кристалла STM32 (позже NTC на радиаторе) |
| Охлаждение | кулер процессора ПК, 4-pin, 25 кГц ШИМ + контроль оборотов |
| Связь | USB CDC, протокол PX-100, то же WPF-приложение |

## Какой АЦП использовать: ADS1115 или встроенный

Для напряжения и тока лучше **ADS1115**, а встроенный АЦП STM32 подходит для температуры:

| | ADS1115 | Встроенный АЦП F401 |
|---|---|---|
| Разрядность | 16 бит | 12 бит |
| Опорное напряжение | своё, внутреннее (погрешность усиления ≤ 0.15 %) | VDDA = 3.3 В от стабилизатора платы (±1…2 %, шумит от USB и ядра) |
| Шаг по напряжению АКБ (делитель 1:11) | около 1.4 мВ | около 8.9 мВ |
| Погрешность при 4.2 В | около ±6 мВ | около ±60…80 мВ |
| Дифференциальный вход (Кельвин) | есть | нет |
| Усилитель (PGA) для малых сигналов (шунт) | есть, ±0.512 В | нет |

Для ёмкостного теста погрешность ±80 мВ слишком велика: отсечка 3.00 В срабатывала бы где-то между 2.92 и 3.08 В, и все мВт·ч были бы занижены или завышены на 2 %. Поэтому U и I измеряет ADS1115, а встроенный АЦП читает датчик температуры кристалла и VREFINT. По VREFINT прошивка находит реальное VDDA и пересчитывает температуру по заводской калибровке.

> **Про «ADS712».** Предполагаю, что имелся в виду датчик тока **ACS712** (Allegro, на эффекте Холла). Прошивка рассчитана на него: модуль ACS712-20A, 100 мВ/А. У этого датчика заметный шум (около ±100 мА) и дрейф нуля. Прошивка сама подстраивает ноль, пока нагрузка выключена, и усредняет показания, но для точных замеров малых токов (< 0.5 А) лучше вариант с шунтом (`CURRENT_SENSOR_SHUNT`, см. ниже).

## Структурная схема

```
                 Кельвин +   ┌──────────── делитель 100k/10k ──► ADS1115 AIN0 ┐
 АКБ + ──[F1 15A]──┬─────────┤                                                 │ U = AIN0 − AIN3
                   │  ACS712 ├──── OUT ── делитель 10k/15k ──► ADS1115 AIN1     │
                   │  (20 A) └──── 5V ─── делитель 10k/15k ──► ADS1115 AIN2     │
                   ▼                                                            │
            ┌──────┴──────┐                                                     │
            │ D1  │  D2   │   два канала: ОУ + MOSFET + шунт 0.1 Ом             │
            │ Q1  │  Q2   │◄── Vset (общая) ◄── RC-фильтр + делитель ◄── PA6 ШИМ│
            │ Rs1 │  Rs2  │                                                     │
            └──────┬──────┘                                                     │
                   │ силовая «звезда» GND                                       │
 АКБ − ────────────┴──────── Кельвин − ── делитель 100k/10k ──► ADS1115 AIN3 ───┘

 BlackPill: USB ──► ПК (приложение WpfApp)
            I2C1 PB6/PB7 ──► ADS1115     PA8 ШИМ / PA1 тахо ──► кулер 4-pin
            PB12 LOAD_OFF ──► 2N7002 (прижимает Vset к земле)
```

## Силовая часть: ОУ + MOSFET + шунт

Классическая схема нагрузки постоянного тока: ОУ сравнивает опорное напряжение Vset с напряжением на шунте и открывает MOSFET ровно настолько, чтобы `I = Vset / Rшунта`.

**60 Вт на один MOSFET в линейном режиме — тяжёлый режим** (SOA и температура кристалла). Поэтому силовая часть сделана из **двух одинаковых каналов** на двух половинах одного сдвоенного ОУ. Опора общая, у каждого канала свой шунт 0.1 Ом. Каждый канал берёт половину тока и половину мощности, а для прошивки это эквивалентно одному шунту 0.05 Ом (`RSHUNT_UOHM = 50000`).

```
 Канал (×2, ОУ A и ОУ B одной микросхемы)

                     +12V
                      │
 Vset ───────────────┤+ \
                      │   >──[R5 100Ω]──┬──────────► затвор Q (IRFP250N)
               ┌──────┤− /              │            сток   ◄── + АКБ (после ACS712)
               │      │                [R6 10k]      исток ──┬── R7 1k ──┐
               │     GND                │                    │           │
               │                       GND              [Rs 0.1 Ом 5 Вт] │
               │                                             │           │
               │                                     силовая «звезда» GND│
               │                                                         │
               └──────────────────┬──────────────────────────────────────┘
                                  │  (вход «−» берёт напряжение верха шунта через R7)
                          [C3 10 нФ] между выходом ОУ и входом «−»
```

* **R7 1 кОм + C3 10 нФ** — частотная коррекция (интегратор). Без неё ОУ с мощным MOSFET почти всегда возбуждается: ёмкость затвора IRFP250N около 2 нФ.
* **R5 100 Ом** — развязка выхода ОУ от ёмкости затвора. **R6 10 кОм** держит затвор закрытым без питания ОУ.
* Обратную связь (R7) подключайте **прямо к верхнему выводу шунта**, отдельным проводником, а не к силовой дорожке.

### Опора Vset: ШИМ → фильтр → делитель

```
 PA6 (TIM3_CH1, 20.5 кГц) ──┬──[R1 5.1k]──┬──[R3 10k]──┬──────► Vset (вход «+» обоих ОУ)
                            │             │            │
                       [R0 100k]     [R2 1k] [C1 1 мкФ] [C2 100 нФ]   сток Q3 2N7002
                            │             │     │      │          ┌──┘ (прижим Vset)
                           GND           GND   GND    GND     затвор ◄── PB12 LOAD_OFF
                                                                   │      + [R4 10k] к 3.3 В
                                                                  исток → GND
```

* Делитель R1/R2: 3.3 В × 1k / 6.1k = 0.541 В при 100 % ШИМ → 0.541 В / 0.05 Ом = **10.8 А** полной шкалы.
* Двухзвенный фильтр (около 190 Гц и 160 Гц) уменьшает пульсации ШИМ до долей мВ (единицы мА тока). Ток через R3 не идёт (вход ОУ), поэтому R3 не влияет на коэффициент деления.
* **Две независимые защиты от самопроизвольного включения:**
  - R0 100 кОм держит PA6 внизу, пока МК в сбросе;
  - Q3 2N7002 с подтяжкой R4 к 3.3 В прижимает Vset к земле, пока прошивка не опустит PB12. Если МК завис, сработает сторожевой таймер (IWDG, около 0.5 с), МК сбросится, и нагрузка выключится.

### Детали силовой части

| Поз. | Деталь | Комментарий |
|---|---|---|
| Q1, Q2 | **IRFP250N** (или IRFP260N, IRFP150N) | планарные MOSFET в TO-247 с хорошей SOA в линейном режиме. «Современные» trench-MOSFET (IRFZ44N, IRF3205 и подобные) в линейном режиме выходят из строя по SOA, их не ставить |
| U1 | **LM358** (или LM2904) | дешёвый вариант: вход до 0 В, питание 12 В. Смещение до 7 мВ даёт до ±70 мА на канал, общую погрешность убирает подстройка в прошивке. Для точных малых токов лучше **OPA2171** или **OPA2192** (36 В, смещение < 0.3 мВ) |
| Rs1, Rs2 | 0.1 Ом, 5 Вт, металлоплёночные или «металлическая полоска» | при 10 А по 5 А на канал: 2.5 Вт на шунт |
| R1/R2 | 5.1 кОм / 1 кОм, 1 % | точность делителя влияет на шкалу тока, прошивка её подстраивает |
| C1 / C2 / C3 | 1 мкФ / 100 нФ / 10 нФ | плёночные или X7R |
| Q3 | 2N7002 | прижим опоры |

## Измерения: ADS1115 и ACS712

```
 ADS1115 (модуль), питание 3.3 В от BlackPill, ADDR → GND (адрес 0x48)

 AIN0 ◄──┬── R 100k ── Кельвин + АКБ        AIN1 ◄──┬── 10k ── ACS712 OUT
         ├── R 10k ── GND                           └── 15k ── GND
         └── 100 нФ ── GND                  AIN2 ◄──┬── 10k ── +5V ACS712
 AIN3 ◄──┬── R 100k ── Кельвин − АКБ                 └── 15k ── GND
         ├── R 10k ── GND
         └── 100 нФ ── GND                  SCL ── PB6, SDA ── PB7, подтяжки 4.7k к 3.3 В
```

* **Напряжение:** два одинаковых делителя 100k/10k (1 %, лучше 0.1 %). ADS1115 измеряет AIN0 − AIN3, то есть напряжение прямо на клеммах АКБ: падение на силовых проводах (при 10 А и 20 мОм это 200 мВ) не учитывается. Диапазон: ±4.096 В × 11 ≈ 45 В шкалы, рабочий до 30 В.
* **Ток (ACS712):** модуль ACS712-20A включается в разрыв + АКБ и питается от 5 В. АЦП питается от 3.3 В, поэтому выход и питание ACS712 идут через одинаковые делители 10k/15k (5 В → 3.0 В). Прошивка считает ток ратиометрически: `I = (OUT − VCC/2) · 5 В / (S · VCC)`. Коэффициент делителя и колебания 5 В при этом сокращаются. Ноль датчика подстраивается автоматически через 2 с после выключения нагрузки.
* **Вариант с шунтом** (`CURRENT_SENSOR_SHUNT`): точнее, но только для **одноканальной** сборки (один MOSFET, один шунт 0.05 Ом, мощность не больше 30…40 Вт на IRFP250N). Верх шунта идёт на AIN3 через 1 кОм (+100 нФ), шкала ±0.512 В, шаг около 0.3 мА. AIN3 занят, поэтому напряжение измеряется относительно GND (одним проводом), и минус АКБ нужно подключать к «звезде» толстым коротким проводом.

## Температура

Сейчас `TEMP_SOURCE_CHIP`: прошивка показывает **температуру кристалла STM32**, как вы просили. Это не температура радиатора. Защита от перегрева по кристаллу (80 °C) сработает только при сильном общем перегреве корпуса.

Когда добавите датчик на радиатор: NTC 10 кОм B3950 от PB0 к GND и 10 кОм от PB0 к 3.3 В, NTC прижать к радиатору между MOSFET, в `load_config.h` указать `TEMP_SOURCE = TEMP_SOURCE_NTC`. Тогда приложение будет показывать температуру радиатора, защита сработает при 85 °C, а вентилятор будет разгоняться от 40 °C (минимум) до 70 °C (100 %).

## Кулер (4-pin кулер процессора ПК)

| Провод кулера | Куда |
|---|---|
| GND (чёрный) | GND |
| +12 В (жёлтый) | +12 В |
| Тахо (зелёный) | PA1, подтяжка **10 кОм к 3.3 В** (не к 12 В: PA1 не толерантен к 5 В) |
| ШИМ (синий) | PA8, режим «открытый сток» (кулер сам подтягивает этот вход) |

* ШИМ 25 кГц по спецификации Intel. Пока нагрузка работает, скорость пропорциональна мощности: 35 % без нагрузки, 100 % от 40 Вт. После выключения кулер ещё 60 с работает на той же скорости, потом останавливается (`FAN_IDLE_PERCENT = 0`; многие кулеры при 0 % всё равно крутятся на минимуме).
* **Контроль кулера:** если при включённой нагрузке обороты ниже 300 об/мин дольше 4 с, нагрузка отключается (авария «кулер»). Для 3-pin кулера (ШИМ через транзистор по питанию, тахо неточный) поставьте `FAN_TACH_CHECK = 0`.

## Питание

* **Вход 12 В / 2 А** (блок питания): кулер (0.3…0.6 А) и ОУ.
* **12 В → 5 В**: понижающий модуль (MP1584, LM2596) для ACS712 и BlackPill (вывод 5V). Между модулем и выводом 5V платы поставьте диод Шоттки (SS14), чтобы USB от ПК и модуль не питали друг друга.
* **3.3 В** берётся со стабилизатора BlackPill (ADS1115, подтяжки).
* Общая земля: силовая «звезда» у шунтов, сигнальная земля (ADS1115, BlackPill) подключена к ней одной точкой.

> GND нагрузки через USB соединён с землёй компьютера. Если испытуемый аккумулятор соединён ещё с чем-то заземлённым, возможна петля. Для полной развязки можно поставить USB-изолятор (ADuM3160).

## Защита (аппаратная)

| Что | Как |
|---|---|
| Короткое замыкание, пробой MOSFET | **предохранитель F1 15 А** (быстрый, автомобильный) в плюсе АКБ. Прошивка не может разомкнуть пробитый MOSFET, она только сообщает об этом (авария «ток при выключенной нагрузке») |
| Переполюсовка АКБ | ток пошёл бы через диоды в MOSFET и шунты. Поставьте **мощный диод Шоттки** (SR1060, MBR2045) параллельно входу после предохранителя, катодом к +: при переполюсовке он сразу сжигает предохранитель |
| Выбросы | TVS **SMBJ33A** параллельно входу |
| Перегрев, обороты, перегрузка | прошивка (см. ниже) |

## Защиты в прошивке

| Авария | Условие (по умолчанию) | Действие |
|---|---|---|
| Отсечка | U ≤ отсечки из приложения (не ниже 0.5 В) дольше 0.3 с | стоп, светодиод 1 Гц |
| Таймер | время теста ≥ таймера | стоп, светодиод 1 Гц |
| Ограничение мощности | I·U > 60 Вт | ток снижается до 60 Вт / U (это ограничение, не авария) |
| Перенапряжение | U > 30 В | не включается / стоп |
| Перегрузка по току | I > цель + 0.7 А дольше 0.3 с, или I > 12 А | стоп, авария |
| Перегрузка по мощности | P > 69 Вт дольше 0.5 с | стоп, авария |
| Перегрев | T ≥ 80 °C (кристалл) / 85 °C (NTC) | стоп, авария; повторный пуск после остывания на 5 °C |
| Кулер | < 300 об/мин дольше 4 с | стоп, авария |
| АЦП | ADS1115 не отвечает или нет питания ACS712 | не включается / стоп |
| Ток при выключенной нагрузке | > 0.5 А дольше 1 с | авария, включение запрещено |
| Нет АКБ | U < 0.3 В при включении | не включается |
| Зависание | сторожевой таймер 0.5 с | сброс МК, нагрузка выключена аппаратно |

Если нагрузка отказалась включаться, приложение покажет *«device did not accept the new value»*. Причину показывает светодиод (5 Гц = авария).

## Тепловой расчёт (60 Вт)

* Кулер процессора с вентилятором: около 0.3…0.4 °C/Вт.
* Два IRFP250N на изолирующих теплопроводящих прокладках (сток на корпусе транзистора, а радиатор не должен быть под потенциалом +АКБ): Rjc 0.7 °C/Вт + прокладка около 0.5 °C/Вт.
* Радиатор: 25 °C + 60 Вт × 0.35 = **46 °C**; кристалл: 46 + 30 Вт × 1.2 = **около 82 °C** при допустимых 175 °C. Запас хороший.
* С одним MOSFET на 60 Вт кристалл нагрелся бы примерно до 118 °C, а главное, в линейном режиме при 20…30 В можно выйти за SOA. Поэтому два канала.
* Основание кулера тонкое (рассчитано на процессор, а не на два TO-247). Если основание алюминиевое, лучше поставить медную пластину 3…5 мм как теплораспределитель.

## Калибровка

1. **Напряжение.** Подайте на вход известное напряжение (лабораторный БП 12 В, контроль точным мультиметром) и посмотрите показание в приложении. Затем: `VSENSE_GAIN_PPM = 1000000 × U_мультиметра / U_приложения`.
2. **Ток.** Мультиметр (или эталонный шунт) последовательно с БП, ток 2…5 А. Затем: `ISENSE_GAIN_PPM = 1000000 × I_мультиметра / I_приложения`.
3. **Уставка тока** калибровки не требует: подстройка в прошивке (`LOAD_TRIM_*`) сама доводит измеренный ток до заданного. Если подстройка всё время упирается в предел (±0.8 А), проверьте номиналы R1, R2 и шунтов.

Значения вписываются в `load_config.h` (или в *Defined symbols* проекта IAR), после чего прошивку нужно пересобрать.

## Первое включение

1. **Без силовой части:** прошить, подключить USB. Светодиод должен вспыхивать раз в 2 с, в системе должен появиться COM-порт, приложение должно подключаться и показывать U ≈ 0. Если светодиод мигает 5 Гц, ADS1115 не отвечает (проверьте I2C и подтяжки).
2. **ОУ без MOSFET:** проверьте осциллографом, что опора Vset без пульсаций, и при Start в приложении растёт плавно, а при Stop падает в 0.
3. **С лабораторным БП вместо АКБ:** 5 В, ограничение тока БП 1 А. В приложении задать 0.5 А и отсечку 3 В, нажать Start. Ток должен быть 0.5 А, кулер должен разогнаться. Плавно снижайте напряжение БП: на 3 В нагрузка должна выключиться.
4. **Мощность:** БП 12 В / 6 А, задать 5 А (60 Вт). Проверьте нагрев радиатора и MOSFET и ограничение мощности: при 8 А должно получиться 60 Вт / 12 В = 5 А.
5. Только после этого подключайте настоящий аккумулятор.
